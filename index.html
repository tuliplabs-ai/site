One thesis

Agentic AI becomes infrastructure only when what agents do is governed: every consequential action weighed against policy before it runs, held for a person when it matters, written to a record that fails verification if anyone edits it. The open-source runtime is the foundation — the platform operates it for a team, the lab's models plug into it, and all three write to the same record.

The runtime · Apache-2.0

Tulip, the runtime

Drop the admission gate around an action your agent already takes.

A refund, a host isolation, an account disable — it runs only after it clears policy, holds for a human when it matters, and lands on a tamper-evident audit trail you can replay. Wraps agents from LangChain, LangGraph, CrewAI, OpenAI Agents, LlamaIndex, and Google ADK — in Python and TypeScript, no rewrite.

Documentation → Source 
# drop the gate around an action your agent already takes
from tulip.control import Action, admit, ControlPolicy, AuditTrail, AdmissionError

policy = ControlPolicy()    # prod → human
trail  = AuditTrail()

risky = Action(name="refund", asset="cust:4821",
              blast_radius=1, kind="payment", environment="production")

try:
    await admit(risky, lambda: refund("cust:4821"), policy=policy, trail=trail)
except AdmissionError as e:
    print(e.decision.outcome)   # → "require_human"; refund NOT run

# Held for a human, on the audit trail. Fool the model; not the runtime.

The lab · P2 Admission

Clusiana-Admit v4

A certified admission classifier — and an honest certificate.

Certified 2026-08-07. The classifier holds no authority: its verdict is combined with the deterministic policy engine's as max(policy, model), so it can raise a decision toward caution and never lower one. A wrong model degrades usefulness, not safety — and its error bound is computed at the level the evaluation set actually randomizes over, not the level that flatters it.

About

Tulip Labs builds the control layer for AI agents that act.

The research is not the marketing arm of the product — it is where the product's claims get attacked in public. A runtime that says "the model cannot talk its way past the gate" and "the record cannot be forged" makes falsifiable claims, and falsifiable claims need a lab the way a lock company needs lockpickers. We publish the methods, merge the fixes upstream, disclose in coordination, and hold our own work to the bar we ask of an agent: state the scope, show the evidence, ship something a defender can run.

How we work

03Defender-first
